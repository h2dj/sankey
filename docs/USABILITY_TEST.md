# 사용성 테스트 대본 (S5)

- 대상 버전: S4 이후 `main` 배포본(또는 `npm run build && npx vite preview`)
- 목적: 기획서 §1 성공 기준 "처음 방문한 사용자가 샘플 또는 자신의 데이터로 첫 차트를 완성하고 내려받을 수 있다"를 실제 실무자로 확인하고, 막히는 곳을 우선순위대로 고친다(계획 T5.1~T5.3).
- 함께 확정할 것: 개발 계획 §2.2 잠정값과 §7 미결정 질문(Q1~Q7) 중 사용자 근거가 필요한 항목(§6)

## 2. 준비

1. 테스트 주소를 **관찰 모드**로 연다: `https://<배포 주소>/?observe=1`
   - 왼쪽 아래 노란 "관찰 모드" 패널이 보이면 된다. 과제마다 [시작] → [성공/실패/건너뜀]을 누른다.
   - 기록에는 **과제 시간, 첫 차트까지 걸린 시간, 오류가 생기고 해결된 횟수(오류 종류 코드만), 내려받은 형식, 편집 횟수**만 남는다. 입력한 값·제목·노드 이름·파일 이름은 남지 않는다(E2E로 검사).
   - 기록은 그 브라우저 탭에만 있고 서버로 가지 않는다. 끝나면 [기록 내려받기]로 JSON 파일을 받아 관찰지와 함께 보관한다. 다음 참여자 전에 [기록 지우기].
2. 참여자마다 **새 브라우저 프로필(또는 시크릿 창이 아닌 새 프로필)**로 시작해 이전 사람의 자동 저장이 남지 않게 한다. 남아 있으면 [새로 만들기] 대신 브라우저의 사이트 데이터를 지운다.
3. 과제 2 파일 `docs/usability/task2-주민참여예산.csv`를 참여자 컴퓨터의 바탕화면에 둔다(엑셀 기본 형식인 EUC-KR로 저장되어 있다).
4. 과제 3 데이터 카드(아래)를 출력하거나 다른 화면에 띄운다.
5. 녹화는 화면만, 동의한 경우에만. 실명·소속은 관찰지에 쓰지 않고 P1, P2…로 적는다.

### 동의 안내(읽어 주기)

> 오늘은 여러분이 아니라 도구를 시험합니다. 막히거나 틀려도 도구의 문제이니 편하게 해 주세요. 생각나는 것을 소리 내어 말해 주시면 큰 도움이 됩니다. 제가 중간에 도와드리지 않을 수 있는데, 어디서 막히는지 보기 위해서입니다. 화면에 입력하시는 데이터는 연습용이고, 도구는 데이터를 서버로 보내지 않습니다. 언제든 멈추실 수 있습니다.

## 3. 과제

진행자는 과제 문장만 읽고, 버튼 이름이나 위치를 말하지 않는다. 참여자가 3분 이상 같은 곳에서 막히면 "지금 무엇을 찾고 계세요?"로 묻고, 그래도 안 되면 힌트(괄호)를 주고 **힌트 사용**으로 기록한다.

### 과제 1. 예시 고쳐서 이미지로 저장 (5분) — 수용 기준 A1·A2·A5

> 화면에 있는 예산 다이어그램에서 '교육' 예산을 40에서 50으로 늘려 주세요. 그다음 보고서에 넣을 이미지 파일로 저장해 주세요.

- 성공: 1행 값이 50이고 PNG(또는 SVG)를 내려받음
- 관찰: 표의 값 칸을 바로 찾는가 / 미리보기가 바뀐 것을 알아채는가 / **'교육으로 들어오는 값(50)과 나가는 값(40)이 다릅니다' 경고를 어떻게 받아들이는가**(무시·당황·하위 항목을 고침) / [내려받기] 창의 형식·해상도 선택을 이해하는가
- 힌트: (값은 왼쪽 표에서 고칩니다) (저장은 위쪽 오른편에 있습니다)

### 과제 2. 받은 CSV 불러와 오류 고치기 (10분) — A3·A4, F-03

> 동료가 엑셀로 정리한 주민참여예산 파일(바탕화면 `task2-주민참여예산.csv`)을 보냈습니다. 이 파일로 다이어그램을 만들고, 문제가 있으면 고쳐 주세요.

파일에 일부러 넣은 문제:

| 행(가져온 뒤) | 문제 | 기대하는 해결 |
|---|---|---|
| 5 | 값 `500만원`(단위를 붙임) | `500`으로 고침(안내 문구가 단위를 빼라고 말함) |
| 7 | 도착지 빈칸 | 도착 노드 입력(예: 쓰레기통 설치) 또는 행 삭제 |
| 9 | 복지 → 복지(자기 자신) | 도착을 바꾸거나 행 삭제 |
| 11 | 값 `0` | 행 삭제(10행과 중복이기도 함) 또는 값 입력 |
| 10·11 | 같은 출발·도착(복지 → 아동 돌봄) | 합산 안내를 이해하는지 확인 |

- 성공: 오류 0건(경고·안내는 남아도 됨), 다이어그램이 보임
- 참고: 고치는 동안 안전·환경·복지에 "들어오는 값과 나가는 값이 다릅니다" 경고가 보일 수 있다(빠진 행 때문). 성공 판정과 무관하지만, 참여자가 이 경고를 어떻게 받아들이는지 기록한다. 파일과 대본이 맞는지는 `src/core/usabilityMaterial.test.ts`가 검사한다.
- 관찰: 가져오기 창의 인코딩·열 맞추기 화면에서 망설이는가 / 단위 "만 원"이 자동으로 들어온 것을 알아채는가 / 오류 목록의 "5행 · 값" 링크를 쓰는가, 표에서 빨간 칸을 직접 찾는가 / 합산 안내를 오류로 오해하는가
- 힌트: (위쪽에 CSV 가져오기가 있습니다) (아래 '입력 확인'의 항목을 누르면 그 칸으로 갑니다)

### 과제 3. 새로 만들어 직접 입력하고 두 형식으로 저장 (12분) — 기획서 §4 흐름 1~5, A5·A6

> 새 다이어그램을 만들어 아래 데이터를 직접 입력해 주세요. 제목은 "우리 동 생활폐기물 흐름", 단위는 "톤"입니다. '매립'의 색을 회색 계열로 바꾸고, 나중에 고칠 수 있게 데이터 파일과 벡터 이미지로 각각 저장해 주세요.

데이터 카드:

| 출발 | 도착 | 값 |
|---|---|---|
| 가정 | 분리배출 | 60 |
| 가정 | 종량제 봉투 | 40 |
| 분리배출 | 재활용 | 45 |
| 분리배출 | 소각 | 15 |
| 종량제 봉투 | 소각 | 30 |

- 성공: 제목·단위가 맞고 6행이 입력됨, 매립 노드 색이 바뀜, CSV와 SVG를 내려받음
- 관찰: [새로 만들기] 창에서 제목·단위를 넣는가 / Tab·Enter로 칸을 옮기는가, 마우스로 하나씩 누르는가 / 엑셀처럼 붙여넣기를 시도하는가 / 노드 색 지정을 찾는가(설정 → 색상 → 노드별 색 지정) / CSV와 SVG의 차이를 이해하는가

### 과제 4. 휴대폰에서 흐름을 눌러 고치기 (5분, 휴대폰 참여자만) — T4.2

> 휴대폰으로 같은 주소를 열어 주세요. 다이어그램에서 '재활용'으로 가는 흐름을 찾아 값을 50으로 바꿔 주세요.

## 4. 설문과 인터뷰

### 과제 직후 한 문항(SEQ)

> 이 과제는 얼마나 쉬웠나요? 1(매우 어려움) ~ 7(매우 쉬움)

### SUS(시스템 사용성 척도) 10문항, 1(전혀 아니다) ~ 5(매우 그렇다)

1. 이 도구를 자주 쓰고 싶다.
2. 이 도구는 쓸데없이 복잡하다.
3. 이 도구는 쓰기 쉽다.
4. 이 도구를 쓰려면 기술적인 도움이 필요할 것 같다.
5. 이 도구의 여러 기능이 잘 어우러져 있다.
6. 이 도구에는 일관되지 않은 부분이 너무 많다.
7. 대부분의 사람은 이 도구를 금방 배울 것이다.
8. 이 도구는 쓰기 번거롭다.
9. 이 도구를 쓰면서 자신감이 있었다.
10. 이 도구를 쓰기 전에 많은 것을 배워야 했다.

점수: 홀수 문항은 (응답−1), 짝수 문항은 (5−응답)을 더해 2.5를 곱한다(0~100). 68 이상이면 평균 이상으로 본다.

### 인터뷰

1. 가장 헷갈렸던 순간은 언제였나요?
2. 평소 업무에서 이런 그림이 필요한 자료는 무엇이고, 지금은 어떻게 만드시나요?
3. 만든 그림을 어디에 넣으시나요?(한글 문서, 파워포인트, 웹, 인쇄물…) 오늘 받은 파일이 그 용도에 맞나요?
4. 오늘 작업을 다른 사람과 나누려면 무엇이 필요할까요?(공유 링크, 파일, 공동 편집…) — 기획서 §13 5단계(확장 판단) 근거
